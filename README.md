# 💻 Laptop Price Predictor

A **Streamlit-based web app** that predicts laptop prices using machine learning. Enter laptop specs like brand, processor, RAM, storage, and OS to get an estimated price.

## 🚀 Features
- Real-time price prediction via web UI
- Clean and user-friendly Streamlit interface
- Trained regression model with feature encoding

## 🧠 Tech Stack
- Python 3.11
- Streamlit
- scikit-learn, pandas, numpy

## ⚙️ How to Run Locally

```bash
git clone https://github.com/sringaribasavesh/Laptop_Price_Predictor.git
cd Laptop_Price_Predictor
python -m venv myenv
myenv\Scripts\activate        # On Windows
pip install -r requirements.txt
streamlit run app.py
